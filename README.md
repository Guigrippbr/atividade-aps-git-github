# Atividade APS 5 – Git e GitHub
Repositório criado como parte de uma atividade acadêmica para demonstrar conhecimentos básicos sobre Git e GitHub.

# Objetivo
Praticar o uso de sistemas de controle de versão e aprender a gerenciar arquivos.

# Ferramentas utilizadas
- Git
- GitHub
- Visual Studio Code

# Atividades realizadas
- Criação de um repositório no GitHub.
- Clonagem do repositório para o computador.
- Edição de arquivos utilizando o VS Code.
- Versionamento de alterações com Git.
- Envio de alterações para o GitHub.
